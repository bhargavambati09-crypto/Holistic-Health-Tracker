- Recovery Auto-Regulator: Detail a system logic that lowers daily step/calorie burn goals if a user logs an injury, muscle fatigue, or low wearable-synced HRV metrics.

5. BEHAVIORAL MECHANICS & DATA INSIGHTS
- Gamification: Design a "Check-off" Streak Calendar system to visually reward consecutive days where core micro-goals are met.

Deliver the response using clear Markdown headers. For each module, provide:
